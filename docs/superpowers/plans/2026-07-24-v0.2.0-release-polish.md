> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add release-ready CI, metadata, community guidance, GitHub settings, and a verified `v0.2.0` pre-release without changing scanner behavior or dependencies.

**Architecture:** Repository-only polish is isolated from the scanner package. A pinned GitHub Actions workflow enforces the existing local contract, a small repository-hygiene test module keeps metadata and community files deterministic, and GitHub mutations occur only after local commits pass every gate. Tag and release publication are last, gated by the exact pushed commit's successful CI run.

**Tech Stack:** Python 3.12–3.14, uv 0.11.7, pytest, Ruff, mypy, GitHub Actions, GitHub CLI, standard-library `pathlib`, `re`, and `tomllib`

- Define rules through the shared check protocol.
- Derive stable configurable IDs from the ordered check registry.

- Keep README commands and examples aligned with real CLI output.

## Supported versions

| Version | Supported |

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/3xpp/RepoDoctor/security/advisories/new).
