GitHub Repo Doctor `v0.2.0` is the project's first public pre-release.

## Highlights

- Scan a local repository with seven deterministic readiness checks.
- Render human-friendly terminal output or stable JSON and Markdown reports.
- Configure enabled checks and global severity deductions with `.repo-doctor.toml`.
- Enforce score thresholds in CI with `--fail-under`.
- Keep policy, environment, symlink, and report-output handling local and safety-first.
- Develop against Python 3.12 or newer with uv, pytest, Ruff, and strict mypy.

## Install from the tagged source

```bash
uv tool install git+https://github.com/3xpp/RepoDoctor.git@v0.2.0
```

The release also includes a source distribution and Python wheel as attached assets.
It is not published to PyPI.

## Verification

The release commit passes unit and end-to-end tests across supported Python versions,
Ruff lint and formatting checks, strict mypy, package builds, fixture scans, JSON
validation, and Repo Doctor's own CI threshold.

## Known limitations

Repo Doctor is local-only and does not use the GitHub API, authenticate, scan
dependencies or vulnerabilities, call AI services, or modify scanned repositories.
It is a repository-readiness tool, not a vulnerability scanner. Docker remains an
optional low-severity readiness signal and is not added to this Python CLI merely to
increase its own score.
